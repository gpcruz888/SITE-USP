# Gestcorp ECA-USP

Site institucional da Especialização em Gestão Estratégica em Comunicação Organizacional e Relações Públicas da ECA-USP.

## Etapa 1 — Home pública

Experiência pública completa da home, com copy institucional, placeholders de imagem, formulário de interesse (interface apenas) e dados estruturados para turmas futuras.

## Desenvolvimento

```bash
npm install
npm run dev
```

Build de produção:

```bash
npm run build
npm run preview
```

## Stack

- React + TypeScript
- Vite
- Tailwind CSS

## Organização

- `src/data` — conteúdo acadêmico, docentes, FAQ, turma e contato
- `src/sections` — seções da home
- `src/components` — UI compartilhada, layout e formulário
- `COPY SITE USP.md` — fonte obrigatória de copy
